# Effeito Pinturas
1. Instale em `C:\xampp\htdocs\Effeito-Pinturas`
2. Inicie Apache e MySQL no XAMPP Control Panel.
3. Acesse `http://localhost/phpmyadmin` e **importe** o banco `effeito.sql` em `Effeito-Pinturas\banco`.
4. Acesse `http://localhost/Effeito-Pinturas/`.
6. Você pode enviar uma mensagem em Contato (bem no fim da página) e um pedido de Orçamento (dentro de cada serviço).
7. Em `servicos`, é possível alterar no phpMyAdmin. Na página inicial, clique em **Atualizar serviços** ou recarregue a página, a listagem vem do banco.
